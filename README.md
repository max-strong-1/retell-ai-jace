# retell-ai-jace

Mr. Jace - AI Executive Assistant voice agent configuration for Retell AI. Includes complete deployment guide and agent setup for managing schedules, emails, and tasks with n8n integration.

- `mr-jace-retell-config.json` - Complete Retell AI agent configuration

Mr. Jace is an AI-powered executive assistant built on Retell AI, designed to manage:

- Email management
- Task organization
- Contact management
- Voice-based interactions with natural conversation flow
